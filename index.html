Home infrastructure — the testbed that found two faults

Infrastructure · Troubleshooting · Linux

Twenty containers on a Proxmox cluster I own, and two hardware faults that took it all offline. Same symptom, every VM off the network and the host frozen. Unrelated causes.

Fault one. A forum post blamed the Intel I219-LM's EEE, ASPM and Wake-on-LAN. Disabling all three held for four days, then the host hung twice more. The real cause sat a layer down: packet offloads tripping an e1000e hardware hang. TSO/GSO/GRO off, stable since.

  1. StartEvery VM loses network at once. The host stops responding.
  2. The forum fixEEE, ASPM and Wake-on-LAN disabled on the Intel I219-LM.
  3. Days 1–4Stable. Looks fixed.
  4. ThenIt hangs twice more, with all three still disabled. The fix was wrong.
  5. Second layerPacket offloads trigger an e1000e hardware-unit hang.
  6. TSO / GSO / GRO offStable since.

Fault two. Same symptom, new cause: the host froze whenever a GPU-passthrough VM started or stopped, because i915 grabbed the device before VFIO could. Loading vfio-pci first fixed it; moving transcoding to the host iGPU removed the problem for good.

The lesson: a fix that seems to work proves nothing. Mine held four days and was still wrong. Full write-ups include the attempt that failed quietly.

Supply chain tracking on Ethereum

Solidity · Dart/Flutter · Testing · Repo

A final-year project I audited and rebuilt because it proved nothing. The screen meant to prove a record was trustworthy read a list stored in the browser, the app called four contract functions that never existed, and its "transaction hashes" were random bytes.

Now the contract is the only source of truth: every read is a chain call, every write returns the chain's own hash, and the ABI is generated, not hand-copied into Dart, which is how the original drifted unnoticed.

The rebuild turned up five more defects, including one that let anyone mark another customer's goods as delivered. Sixty-four assertions now cover every flow the app uses, and prove those attempts fail.

  • 23 contract functions · 11 events
  • Forward-only shipment status, owner-gated attestation
  • Stock checked and decremented on chain
  • 64 passing assertions

CIDR Atlas: a subnet calculator

JavaScript · IPv4 & IPv6 · Testing

An IPv4 and IPv6 subnet calculator that shows the bits, so you watch the network and host split move as the prefix changes. It splits blocks, plans VLSM largest-first, merges and subtracts network lists, and drafts config for Cisco, Huawei, MikroTik and Linux. A CLI shares the same engine.

Checked against Python's ipaddress on 1,050 random cases plus unit tests. Runs in the browser, no dependencies, no build step.

Network scanner and small tools

Python · Flask · Nmap · Ruby

Point it at a subnet and it sweeps the range on a schedule, logging what answers. The hard part was making it stop: a thread per request piles up, and a scan you can't interrupt is a scan you can't kill when it finds something odd. One scheduler thread, an interruptible loop, a stop button that works at once.
