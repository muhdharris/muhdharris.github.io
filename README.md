# muhdharris.github.io

Personal site — live at https://muhdharris.github.io

Hand-written HTML, CSS and one small WebGL scene. No framework, no template. A small
build step (esbuild) bundles and minifies `src/` into `dist/`.
Paper-and-ink design, dark and light mode via `prefers-color-scheme`. Fonts are self-hosted.

## Files

```
index.html             the whole site, single page
src/                   the source: styles.css, and the scripts below
  main.js              entry point; loads the rest, 3D and demo after the page
  lib.js               shared helpers and one scroll scheduler
  motion.js            scroll effects: hop counter, progress, parallax, timeline
  cursor.js            traceroute cursor (mouse only, off for reduced motion)
  rail.js              section rail on the left edge (wide screens)
  net.js               hero scene: the homelab as a 3D schematic (three.js)
  storm.js             the STP loop demo
dist/                  built, minified output the page serves (committed for Pages)
build.mjs              the build: `npm install && npm run build`
fonts/                 Instrument Serif and IBM Plex, self-hosted
infra-topology.svg     homelab diagram, drawn in the dark palette
og-image.png           1200x630 share card for link previews
Muhd-Harris-CV.pdf     CV
```

## Notes

The site is static and deploys straight from `main`. Edit `src/`, run
`npm run build`, and commit `dist/` with it, because Pages serves the files as they are.
three.js is installed from npm and tree-shaken to the classes the scene uses; it
loads as its own chunk after the page has painted.

`Muhd-Harris-CV.pdf` is generated by `.build/build_cv.py`, which is not published.
It is a small PDF writer with no dependencies, and it measures text against real
Helvetica widths so lines do not wrap early. It refuses to write if the content
would overflow one page, so a too-long edit fails loudly instead of producing a
clipped second page. Run it from the repository root.
